# JAX

Mission

Build an Executive AI Assistant that becomes my personal operating system.

JAX should:

• Understand me
• Remember important information
• Help manage my work and personal life
• Proactively assist me
• Continuously improve over time

Core Principles

• Executive Assistant
• Voice First
• Offline First
• AI Assisted
• Privacy First
• Modular
• Reliable

Non Goals

• Build another chatbot
• Build every feature immediately
• Over engineer the architecture

Success Criteria

If I use JAX every day instead of writing notes manually,
the project is successful.
